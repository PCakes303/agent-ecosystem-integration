# Agent Ecosystem Integration

MrCakes931 Agent Intelligence Ecosystem · Interoperability layer

Defines adapters, integration profiles, and conformance expectations for connecting ecosystem repositories and external agent systems.

## Scope
- Explicit protocol and version boundaries.
- MCP, A2A, OpenAPI, JSON Schema, and OpenTelemetry integration profiles.
- Identity, authorization, provenance, correlation, and error propagation.
- Bounded retries, timeouts, backpressure, and idempotency.

## Current status
Scaffolded, version 0.1.0. See [docs/INTEGRATION.md](docs/INTEGRATION.md), [docs/ADAPTER-CONTRACT.md](docs/ADAPTER-CONTRACT.md), and [examples/integration-profile.json](examples/integration-profile.json).

Named standards are integration targets, not claims of completed implementations or certification.
